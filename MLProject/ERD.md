# 서울시 골목상권 폐업위험 조기경보 — 데이터 구조 (ERD)

분석 단위는 **상권 × 서비스업종 × 분기**임. 기간은 2023Q1~2025Q4이며,
2025Q4의 라벨을 만들기 위해 2026Q1까지 적재함.

출처는 전부 **서울시 우리마을가게 상권분석서비스**(서울특별시 주관 / 서울신용보증재단 위탁운영)이며,
서울 열린데이터광장을 통해 배포됨. 공공누리 1유형.

## 2. 테이블 명세

| 테이블 | 기본키 | 단위 | 역할 | 비고 |
|---|---|---|---|---|
| **영역-상권** | `상권_코드` | 상권 | 마스터 — 유형·행정구역·좌표·면적 | 분기 개념 없음. 좌표는 EPSG:5181(미터) |
| **점포-상권** | `분기 + 상권 + 업종` | 상권×업종×분기 | **라벨 원천**, 규모 | 국세청 사업자등록 기반 |
| **추정매출-상권** | `분기 + 상권 + 업종` | 상권×업종×분기 | 매출 | 카드 매출이 잡히는 칸에만 존재 |
| **길단위인구-상권** | `분기 + 상권` | 상권×분기 | 유동인구 총량 | 생활인구를 10m 단위로 배분 |
| **직장인구-상권** | `분기 + 상권` | 상권×분기 | 상권 성격 | **연 1회 갱신** → 준고정 변수 |
| **상주인구-상권** | `분기 + 상권` | 상권×분기 | 상권 성격 | |
| **집객시설-상권** | `분기 + 상권` | 상권×분기 | 입지 | 빈칸이 곧 0 |
| **상권변화지표-상권** | `분기 + 상권` | 상권×분기 | **기준선 전용** | 피처로 쓰지 않음 |

## 3. 결합 순서와 카디널리티

```
                    ┌─ 영역-상권 ─────────── 1 : N ──┐
                    │  (상권 마스터)                  │
                    │                                ▼
 길단위인구 ─┐       │                        ┌──────────────────────┐
 집객시설   ─┼─ 1:N ─┤                        │  분석 패널            │
 popmix    ─┤  (분기+상권)                    │  상권 × 업종 × 분기   │
 상권변화지표 ┘       │                        └──────────────────────┘
                    │                                ▲
                    └─ 추정매출 ─── 1 : 1 ───────────┘
                       (분기+상권+업종)
```

좌결합(left join)을 기준 테이블인 **점포-상권**에 대해 6회 수행하며,
매 단계에서 **행 수가 늘면 즉시 중단**함. 행 증식은 곧 키 중복을 뜻하고,
뒤로 갈수록 원인을 찾기 어려워지기 때문임.

| 순서 | 붙이는 테이블 | 키 | 관계 |
|---|---|---|---|
| 1 | 영역-상권 | `상권_코드` | N : 1 |
| 2 | 길단위인구 | `분기 + 상권` | N : 1 |
| 3 | 집객시설 | `분기 + 상권` | N : 1 |
| 4 | popmix(직장+상주) | `분기 + 상권` | N : 1 |
| 5 | 상권변화지표 | `분기 + 상권` | N : 1 |
| 6 | 추정매출 | `분기 + 상권 + 업종` | 1 : 1 |

## 4. 파생 변수

| 변수 | 산식 | 출처 테이블 |
|---|---|---|
| `순증감` | `개업_점포_수 − 폐업_점포_수` | 점포 |
| **`y` (라벨)** | `1 if 순증감(t+1) < 0 else 0` | 점포 |
| `직장인구_비중` | `직장 ÷ (직장 + 상주)` | 직장 + 상주 |
| `역세권` | `지하철_역_수 > 0` | 집객시설 |
| `점포밀도` | `업종 점포수 ÷ 상권 전체 점포수` | 점포 |
| `프랜차이즈비율` | `프랜차이즈 ÷ 전체 점포수` | 점포 |
| `점포당매출` | `당월_매출_금액 ÷ 전체_점포_수` | 점포 + 매출 |
| `log_*` | 면적·점포수·유동인구·집객시설의 로그 | 각 원본 |

`분기idx = (코드 // 10) × 4 + (코드 % 10 − 1)` 로 분기를 연속 정수로 바꿔
`20244 → 20251` 연도 경계에서도 차이가 1이 되도록 함. 라벨은 이 차이가 1인 경우에만 생성함.

## 5. 결합 검증 절차

1. **분기별 상권 코드 집합 일치** 확인 — 코드 폐지·신설을 추적함
2. **조인 전후 행 수 대조** — 좌결합 6회 모두 기준 행 수를 유지해야 함
3. **키 유일성 사전 확인** — 결합 전에 각 테이블의 `duplicated(키)` 가 0인지 검사함
4. **상권 커버리지 확인** — 영역-상권 1,650개 대비 각 테이블의 누락 상권 수를 기록함
5. **결측률 기록** — 30% 초과 변수는 공변량에서 제외함

## 6. 스키마 변경 이력 (중요)

서울시가 **2024년부터 공간 단위를 표준단위구역으로 변경**했고, 이 과정에서
연도별 배포 파일의 컬럼명이 바뀜. 두 이름이 가리키는 대상이 다르므로 반대로 매칭하면
표본 크기와 척도가 어긋남.

| 2023 · 2024 파일 | 2025~ 파일 | 검증식 |
|---|---|---|
| `유사_업종_점포_수` | `전체_점포_수` | `전체 = 일반 + 프랜차이즈` |
| `점포_수` | `일반_점포_수` | (100% 성립 확인) |

**Open API(`VwsmTrdarStorQq`)는 전 기간이 하나의 스키마**이므로 이 문제가 발생하지 않음.
본 분석은 API 통합본을 우선 사용하고, 없을 때만 연도별 파일로 되돌아감.

## 7. 이 구조에서 답할 수 없는 것

- **임대료** — 상권 단위 데이터가 존재하지 않음(한국부동산원은 자치구·별도 상권 체계, 서울시 상가임대차 실태조사는 2023년까지·연 1회)
- **소비** — 상권 단위 데이터는 갱신이 중단됨. 자치구·행정동 집계와 상권 집계는 **원천이 다름**을 제공처가 명시함
- **업종 간 선후 관계** — 12분기로는 선후를 판정하기에 짧음
