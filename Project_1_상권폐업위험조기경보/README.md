# 서울시 골목상권 폐업위험 조기경보

> **핵심 질문** — 다음 분기에 점포 순감소(폐업 > 개업)로 전환될 상권 × 업종은 어디이며, 무엇이 위험을 만드는가

AI 데이터 인텔리전스 「Project #1 Insight Digging with ML」. 데이터셋 후보 8번(서울시 상권분석).

## 구성

| 파일 | 내용 |
|---|---|
| `상권_폐업위험_데이터준비_EDA.ipynb` | 적재 → 결합 → 라벨 → 기초 탐색 → 기준선·가설 검토 |

**실행 순서** — EDA 노트북을 먼저 돌려야 함. 모델링 노트북은 EDA가 만드는
`data/processed/04_model_input.csv` 를 입력으로 받음. 두 노트북 모두 실행 결과가
셀 출력으로 저장되어 있어 열어 보기만 해도 결과를 확인할 수 있음.

## 분석 단위와 기간

| 항목 | 값 |
|---|---|
| 분석 단위 | 상권 × 서비스업종 × 분기 |
| 업종 범위 | 요식업 10종 |
| 기간 | 2023Q1 ~ 2025Q4 (라벨 생성을 위해 2026Q1까지 적재) |
| 라벨 | `y(t) = 1 if 개업_점포_수(t+1) − 폐업_점포_수(t+1) < 0 else 0` |
| 표본 | 67,475칸 (점포 5개 이상) · 양성률 25.5% |
| 피처 | 52개 → 원-핫 후 88개 |

**시점 분할** — 학습 2023Q1\~2025Q2 (56,496칸) / 검증 2025Q3 (5,500칸) / 테스트 2025Q4 (5,479칸).
각 분기는 그 다음 분기의 결과로 채점함. 무작위로 섞지 않고 시간 순서로 자름.
`2026Q1`은 예측 대상이 아니라 **2025Q4의 라벨을 만들기 위해서만** 적재함.

## 데이터

**출처** — 서울시 우리마을가게 상권분석서비스 (서울특별시 주관 / 서울신용보증재단 위탁운영).
배포는 서울 열린데이터광장(`data.seoul.go.kr`), 공공누리 1유형.

원천은 추정매출 = 신한카드 결제액 ÷ 보정비율, 유동인구 = 서울시·KT 생활인구,
점포 = 국세청 사업자등록 기반임. 이 때문에 **「폐업」은 실제 폐점이 아니라 사업자등록 말소 시점**이며,
매출은 단일 카드사 기반 추정치임.

`데이터/` 안의 파일은 **gzip으로 압축해 보관**함. 원본 CSV 두 개가 GitHub의 파일당 100MB 제한을
넘기 때문임. 노트북의 `path()` 헬퍼가 `.csv` 와 `.csv.gz` 어느 쪽이든 읽음.

| 파일 | 압축 후 | 원본 |
|---|--:|--:|
| 점포-상권_API | 10.1 MB | 134.6 MB |
| 추정매출-상권_API | 75.8 MB | 197.4 MB |
| 길단위인구 · 집객시설 · 상권변화지표 · 영역 | 3.6 MB | 14.1 MB |

다른 경로의 원본을 쓰려면 환경변수로 지정함.

```bash
set SANGKWON_RAW=D:\somewhere\데이터
```

중간 산출물(`data/processed/`)과 그림(`figures/`)은 `.gitignore`로 제외함 —
용량이 크고 노트북을 돌리면 다시 만들어짐. 그림은 노트북 셀 출력에 그대로 들어 있음.

### 쓰지 않은 데이터와 그 이유

- **직장인구 · 상주인구** — `직장인구_비중`을 만들어 넣어 봤으나 단변량 AUC 0.520으로
  판별력이 없어 제외함.
- **전국 단위 경제지표**(물가지수·소비자심리지수·대출금리 등) — 분기 단위 전국 값이라
  **한 분기 안에서 모든 상권이 같은 값**이 됨. 평가가 한 분기 안의 순위이므로
  순위를 바꿀 수 없어 제외함. 업종별 지표를 만들어도 업종 범주형과 완전 공선이라 같음.
- **임대료 · 상권 검색량** — 상권 코드로 결합할 수 있는 형태의 자료를 구하지 못했음.
  부동산원 임대료는 자체 상권 체계, 네이버 데이터랩은 상권명 기준이 달라 매칭이 안 됨.
- **상권 경계 폴리곤(Shapefile)** — 저장소에 없어 단계구분도(주제도)를 그리지 못했음.
  좌표 기반 네 레이어로 대체함.

## 결과

### 모델 선정

같은 검증 분기(2025Q3)에서 5종을 비교함. **다섯 모델의 PR-AUC가 0.388 ~ 0.407에 몰려 있음** —
모델 종류를 바꿔서 얻는 이득이 거의 없고, 쓸 수 있는 변수가 이미 한계라는 신호임.

| 모델 | PR-AUC |
|---|--:|
| 로지스틱 회귀 | 0.407 |
| 선형 SVM | 0.407 |
| 랜덤포레스트 | 0.403 |
| 의사결정나무 | 0.395 |
| **XGBoost (채택)** | 0.388 |

**XGBoost는 1위가 아님.** 그래도 채택한 이유는 차이가 0.02 미만이라 결론이 바뀌지 않고,
`TreeExplainer`로 정확한 SHAP 분해가 되는 유일한 축이기 때문임 — 과제 후반부 질문이
«무엇이 위험을 만드는가»이므로 해석 도구가 필요함. 1위 모델과는 테스트 분기에서 나란히 보고함.

정확도로 고르지 않은 이유는 «전부 0으로 찍기»만 해도 정확도가 74.7% 나오기 때문임.

### 가장 중요한 결과 — 전체 Lift와 층화 Lift를 함께 봐야 함

테스트 2025Q4에서 **모델은 «점포 수» 기준선을 이기지 못함.**

| 방법 | Lift |
|---|--:|
| 로지스틱 회귀 | 1.654 |
| 점포 수 상위 1,285칸 | **1.645** |
| 2단계 모형 | 1.566 |
| XGBoost | 1.507 |
| 직전 분기 | 1.199 |
| 상권변화지표(HL) | 0.937 |

그런데 **점포 수 5분위 안에서는 다섯 구간 모두 모델이 이김.**

| 규모구간 | 평균 점포 | 기저율 | 모델 Lift | 점포 수 Lift |
|---|--:|--:|--:|--:|
| Q1 | 5.4 | 13.3% | **1.606** | 0.981 |
| Q2 | 7.8 | 18.6% | **1.385** | 1.180 |
| Q3 | 11.7 | 23.1% | **1.368** | 1.254 |
| Q4 | 19.5 | 31.6% | **1.214** | 1.166 |
| Q5 | 66.1 | 42.8% | **1.173** | 1.131 |

**모순이 아님.** 기저율이 Q1 13.3% → Q5 42.8%로 3배 이상 벌어져 있어서,
«점포 수» 규칙은 큰 칸만 골라내면 자동으로 기저율 높은 구간에 들어앉음.
위험을 읽은 것이 아니라 위험이 흔한 동네를 고른 것이고, 구간 안으로 들어가면
그 규칙의 Lift는 0.98\~1.25로 거의 무작위가 됨.

「점포 수 상위를 보라」는 「큰 상권을 보라」와 같은 말이라 정책적으로 쓸 정보가 없음.
조기경보에 필요한 것은 **같은 크기의 칸들 사이에서 누가 위험한지**이고 그건 모델만 함.
**발표에서 두 표를 붙여서 제시해야 결론이 성립함.**

### 무엇이 위험을 만드는가 (SHAP)

규모·밀도 계열이 기여의 **59.2%**, 그 밖이 40.8%.

| 변수 | 평균 &#124;SHAP&#124; |
|---|--:|
| 전체_점포_수 | 0.328 |
| 점포당매출 | 0.105 |
| 개업_점포_수 | 0.103 |
| 업종_점포밀도 | 0.074 |
| 업종 = 한식음식점 | 0.066 |
| 업종점포비중 | 0.059 |

막대 그래프(기여 크기)와 벌떼 그래프(기여 방향)를 함께 넣음. EDA 3-1에서 우려한
«규모를 배우는 문제»가 59.2%라는 수치로 확인됨.

### 위험도 지도 (GIS)

좌표계는 `EPSG:5181`(미터) → `EPSG:4326`(위경도). **그릴 때는 위경도, 잴 때는 원본 미터 좌표**로
두 벌을 유지함 — 위경도는 1도의 실제 길이가 위도마다 달라 뺄셈으로 거리를 구할 수 없음.

**좌표계 검증은 «실제로 어디인지 아는 상권»으로 함.** 후보 좌표계들이 서울 안에서 2km 이내로
붙어 있어 경계 상자만으로는 갈라지지 않기 때문임. 지하철역 상권 6곳의 실제 위경도와 대조해
`EPSG:5181`을 확정함(강남역 오차 0.04km). 서울 경계 상자 밖 좌표는 0건.

**위험등급은 눈금이 아니라 데이터가 정함.** 위험점수 4분위로 자르고 각 등급의 실제 순감소율로 검증함.

| 등급 | 칸수 | 실제 순감소율 | 기저율 대비 |
|---|--:|--:|--:|
| 관찰 | 1,370 | 15.3% | 0.59 |
| 주의 | 1,370 | 20.2% | 0.78 |
| 경계 | 1,369 | 29.1% | 1.12 |
| **위험** | 1,370 | **39.3%** | **1.51** |

네 등급이 단조 증가하므로 지도에 그대로 쓸 수 있음. 설계서가 쓴 «순증감률 ±2%» 기준을
같은 데이터로 재보면 **순서가 뒤집힘** — `0~+2%` 칸이 표본 98개뿐인데 순감소율이 가장 높게
튀어(기저율 대비 1.77) 지도 색이 위험 순서를 나타내지 못함.

**구현 레이어** — 버블 분포도 / 500m 격자 / 동심원 / 공간 평활.
격자는 678개(칸 3개 이상), 지도 표본은 상권 1,357곳(각 상권의 최고 위험 업종 기준).
QGIS·웹지도용 포인트 GeoJSON도 함께 저장함.

**동심원 분석은 음성 결과** — 역 밖 네 구간의 위험이 0.457\~0.504로 평평하고 순서도 맞지 않음.
유일하게 두드러지는 «역세권 상권 자체»(0.636)는 평균 점포가 49.6개로 나머지(18\~22개)보다
2.4배 이상 커서 거리 효과가 아니라 규모 효과임. 역 좌표 자료가 없어 `지하철_역_수 > 0` 인
상권 중심점을 **대리 위치**로 쓴 한계도 있음.

## 방법상 지킨 것

1. **기준선을 먼저 세움** — 무작위 / 직전 분기 / 서울시 상권변화지표 / 점포 수.
2. **`y=0`을 분해함** — 「변화 없음」(개·폐업 0건)과 「변화 있었으나 줄지 않음」의 합임.
   **상권 규모가 작은 곳에서 「변화 없음」의 빈도가 높음**(평균 점포 5.4개 구간 69.3% →
   65.5개 구간 7.9%). 라벨이 규모에 끌려가는 통로가 이것임.
3. **불균형은 분할 이후 가중치로만** — 분할 전 오버샘플링은 복제된 소수 클래스가
   학습·검증에 함께 들어가 성능을 부풀림.
4. **t+1 정보는 어떤 형태로도 피처에 넣지 않음.** `상권_변화_지표`는 폐업 정보로 만들어져
   라벨과 원천이 같으므로 피처가 아니라 기준선으로만 씀.
5. **상권 식별 정보와 시간 축을 피처에서 뺌** — 상권 코드·좌표·행정동은 모델이 상권을 외우게 하고,
   분기 번호는 한 분기 안에서 상수라 순위에 기여하지 못함.
6. **테스트 분기는 마지막에 한 번만.** 임계값은 검증 분기에서 정한 것을 그대로 옮김.

## 참고 문헌

「코로나19 전후 요식업 예비창업자들을 위한 폐업예측 모델 제안 및 폐업에 미치는 요인 분석」 —
같은 5종 비교에서 XGBoost를 선정하고 SHAP으로 해석하는 구성을 참고함.

다만 두 가지는 따라가지 않았음. ① 그 논문은 분할 전 오버샘플링으로 11.07% → 50:50을 맞춘 뒤
정확도 0.933을 보고하는데, 복제된 소수 클래스가 학습·검증에 함께 들어간 것으로 보임.
② 그 논문은 **개별 업체 × 인허가 시점** 코호트 구조라 전국 경제지표가 행마다 달라 판별력을
가졌음(3년내 폐업 SHAP 1위가 소기업대출금리). 이 과제는 상권 × 분기 패널이고 시점을 고정해
평가하므로 같은 변수가 상수가 됨 — 구조가 달라 이식되지 않음.
